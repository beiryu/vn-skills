## Notes

- 34 provinces / 3,321 ward-level units after the 01/07/2025 rearrangement, incl. later decrees. Source of codes, names, English names, postal codes.
- Pre-2025 63-province / district / ward catalogue, search keywords, and the old→new ward mapping (incl. divided wards).
- NAPAS BIN list with VietQR support flags and SWIFT codes.
- Three provinces (Bắc Ninh, Quảng Ninh, Đồng Nai) became centrally-run cities after the mapping dataset was published; the mapping is joined by GSO code so it survives the rename.
- Divided old wards keep every new candidate; exactly one is flagged default. Street-level disambiguation is not attempted.
