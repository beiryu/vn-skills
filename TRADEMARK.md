# Name and brand policy

The code is MIT-licensed. The **name "vn-skills"**, the `@vn-skills` npm scope, the `beiryu/vn-skills` repository and
any project logo are the project's identity and are **not** covered by the MIT license. This policy keeps users from
being confused about what is official.

## You may, without asking

- Say your product "uses vn-skills", "is built on @vn-skills/core" or "is compatible with vn-skills".
- Fork the repository and keep the name **in your fork's repo while it tracks upstream** for the purpose of contributing back.
- Write articles, talks and tutorials about vn-skills.

## Please don't

- Publish packages, skills, MCP servers or apps named `vn-skills`, `@vn-skills/*`, `vnskills` or a confusingly similar
  name, or under the `vn-skills` name on any registry (npm, PyPI, skill marketplaces, MCP registries).
- Distribute a modified version under the vn-skills name. Rename your fork if you publish it.
- Imply endorsement, partnership or certification by vn-skills, NAPAS, a bank, or a Vietnamese authority.
- Use the name in domain names or social handles.

## Official channels

| Channel        | Location                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------- |
| Source         | https://github.com/beiryu/vn-skills                                                       |
| npm            | `@vn-skills/core`, `@vn-skills/cli`, `@vn-skills/mcp` (published from CI with provenance) |
| PyPI (planned) | `vn-skills`                                                                               |

Anything else claiming to be vn-skills is unofficial. Report impersonation via a
[private advisory](https://github.com/beiryu/vn-skills/security/advisories/new).
