# Code of Conduct

vn-skills adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Tiếng Việt: [bản dịch](https://www.contributor-covenant.org/vi/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code rather than people, and keep discussions on topic. Harassment,
discriminatory language and personal attacks are not tolerated in issues, PRs, Discussions or any project space.

## Reporting

Report incidents privately to the maintainers through a
[private security advisory](https://github.com/beiryu/vn-skills/security/advisories/new) (choose "Code of conduct" in
the title) or by direct message to a maintainer listed in [GOVERNANCE.md](GOVERNANCE.md). Reports are kept confidential.
Maintainers apply the Covenant's enforcement guidelines (correction → warning → temporary ban → permanent ban).
